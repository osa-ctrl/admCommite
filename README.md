# ts-downloader

Скрипт на Python: по ссылке на один TS-сегмент или на плейлист `.m3u8`
скачивает все сегменты по порядку и склеивает их в один MP4 через FFmpeg.

## Требования

- Python 3.9+ (сторонние библиотеки не нужны)
- FFmpeg в `PATH` (или путь к нему через `--ffmpeg`)
  - Windows: `winget install ffmpeg`
  - macOS: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg`

## Использование

```bash
python3 ts_download.py "https://host/path/seg-2-v1-a1.ts" -o video.mp4
```

Скрипт находит номер сегмента в имени файла (здесь `2` в `seg-2-v1-a1.ts`),
качает `seg-1-v1-a1.ts`, `seg-2-v1-a1.ts`, `seg-3-v1-a1.ts`… пока сервер не
ответит 404, и склеивает их командой
`ffmpeg -f concat -safe 0 -i list.txt -c copy video.mp4` (без перекодирования).
Query-параметры ссылки (например, токены) и ведущие нули (`seg-007`) сохраняются.

Сегменты скачиваются параллельно, по 8 штук одновременно. Если загрузка всё
равно идёт медленно, увеличьте `-j`, например `-j 16`. Если сервер начинает
отвечать ошибками, уменьшите это число.

### Плейлист m3u8

```bash
python3 ts_download.py "https://host/path/index.m3u8" -o video.mp4
```

Скрипт скачивает сегменты в том порядке, в каком они перечислены в плейлисте.
Если это master-плейлист с несколькими качествами, скрипт выводит их список
и берёт вариант с самым высоким битрейтом. Другой вариант можно выбрать
через `--variant N`. Плейлисты с шифрованием (`#EXT-X-KEY`) и с fMP4-сегментами
(`#EXT-X-MAP`) не поддерживаются, в этих случаях скрипт выдаёт ошибку.

### Параметры

| Параметр | Что делает |
|---|---|
| `-o, --output FILE` | итоговый файл (по умолчанию `output.mp4`) |
| `--start N` | с какого номера начинать (по умолчанию 1); для плейлиста это номер записи |
| `--max N` | скачать не больше N сегментов |
| `--group N` | какое по счёту число в имени файла считать номером сегмента, если автоопределение ошиблось (в `seg-2-v1-a1.ts` это 1) |
| `--variant N` | какой вариант качества взять из master-плейлиста (по умолчанию самый высокий битрейт) |
| `-H 'Имя: значение'` | доп. HTTP-заголовок, можно несколько раз (например, `Referer`, `Cookie`) |
| `-j, --workers N` | сколько сегментов качать одновременно (по умолчанию 8) |
| `--retries N` | попыток на сегмент при сетевых ошибках и ответах 5xx (по умолчанию 5) |
| `--keep DIR` | сохранить скачанные сегменты в папку DIR |
| `--ffmpeg PATH` | путь к ffmpeg |

Полный список: `python3 ts_download.py --help`.

### Как определяется номер

1. Число сразу после `seg`, `segment`, `frag`, `chunk`, `part`, `media`
   (`seg-2-v1-a1.ts` → 2, `segment007.ts` → 7).
2. Иначе последнее число в имени файла (`720p_15.ts` → 15).
3. Если и это не то, укажите `--group`.

Если сервер требует `Referer` или куки, передайте их через `-H`, иначе он
может ответить 403 вместо сегмента.

## Веб-версия

В репозитории есть небольшой сайт поверх этого же скрипта: вставляете ссылку,
видите прогресс, по окончании скачиваете MP4. Вход по одному общему паролю.
Готовые файлы хранятся на сервере 60 минут, потом удаляются.

- `server/app.py` — бэкенд на FastAPI, запускает `ts_download.py` и читает его прогресс
- `frontend/` — страница (React, Tailwind, компоненты shadcn/ui, тема «Modern Minimal» из tweakcn)
- `Dockerfile` — собирает всё в один контейнер с FFmpeg

Запуск в Docker:

```bash
docker build -t ts-web .
docker run -p 8000:8000 -e APP_PASSWORD='придумайте-пароль' ts-web
```

Откройте http://localhost:8000. Как выложить на хостинг, написано в [DEPLOY.md](DEPLOY.md).

Локальная разработка без Docker:

```bash
pip install -r server/requirements.txt
APP_PASSWORD=test uvicorn server.app:app --reload     # бэкенд на :8000
cd frontend && npm install && npm run dev             # страница на :5173
```
